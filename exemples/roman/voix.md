# Fiche de voix — La Nuit du quai nord

> Exemple fictif. Modèle dans `skills/roman/references/voix-et-style.md`.

- **Narration** : troisième personne, focalisation interne sur Mathilde Arnaud, passé simple.
- **Phrase** : courte et concrète dans l'action ; plus ample dans les souvenirs. Peu d'adjectifs, aucun adverbe de manière quand un verbe précis suffit.
- **Dialogues** : tiret cadratin, incises brèves (« dit-elle », « demanda Morel ») ; les dockers parlent par phrases coupées, Mathilde pose des questions fermées.
- **Images** : tirées du port (rouille, huile, câbles, marées), jamais de métaphore savante.
- **Ton** : retenu ; l'émotion passe par les gestes et les objets, pas par les mots qui la nomment.
- **À éviter** : « soudain », « sembla », les fins de chapitre en question rhétorique.
