# Personnages

> Exemple fictif. Les lignes « - clé : valeur » alias, naissance et mort sont lues par les scripts ; les autres servent au dessinateur (fiche de personnage).

## Aki Moreau
- alias : Aki
- naissance : 2014
- rôle : protagoniste
- apparence : douze ans, cheveux noirs coupés court, ciré jaune trop grand, bottes rouges
- expression type : sourcils froncés quand elle réfléchit, bouche ouverte quand elle s'étonne

## Rose Moreau
- alias : Rose, grand-mère
- naissance : 1948
- rôle : grand-mère d'Aki, ancienne gardienne du phare
- apparence : petite, cheveux blancs en chignon, gilet de laine vert, mains abîmées
- secret : elle sait ce que guide le phare
