# Fiche de voix — Marées

> Exemple fictif. Modèle dans `skills/roman/references/voix-et-style.md`.

- **Narration** : première personne, passé composé ; une narratrice adulte qui se souvient.
- **Phrase** : courte, concrète ; une phrase plus longue pour le moment qui bascule.
- **Dialogues** : rares, au tiret cadratin ; les personnages âgés parlent peu et juste.
- **Images** : la mer, le vent, les objets du littoral ; jamais de métaphore abstraite.
- **Ton** : retenu ; l'émotion arrive par un geste dans la dernière phrase.
- **À éviter** : « soudain », les explications de ce que la chute a déjà fait sentir.
